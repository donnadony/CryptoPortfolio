# CryptoPortfolio - Setup 🚀

**Quick setup guide**

---

## 📋 Prerequisites

- Xcode 15+
- iOS 17+
- macOS Sonoma+

---

## 🚀 Quick Start

### 1. Open Project
```bash
open CryptoPortfolio.xcodeproj
```

### 2. Add Files to Xcode
All source files are already in the correct folders:
- Core/Network/
- Features/Portfolio/
- Theme/
- Navigation/

Right-click project → Add Files → Select folders → Add

### 3. Build & Run
```bash
⌘ + B  # Build
⌘ + R  # Run
```
