# CryptoPortfolio 📱💰

**iOS Cryptocurrency Portfolio Tracking App**

Track your crypto investments with real-time prices and beautiful UI.

---

## 🎯 Features

- ✅ Portfolio tracking (add/edit/delete assets)
- ✅ Real-time price updates (CoinGecko API)
- ✅ Total portfolio value calculation
- ✅ Asset detail view with charts
- ✅ Market browser
- ✅ Settings & preferences

---

## 🛠️ Tech Stack

- **SwiftUI** - Modern declarative UI
- **MVVM** - Clean architecture
- **Combine** - Reactive state management
- **Async/await** - Modern concurrency
- **CoinGecko API** - Free crypto data

---

## 📂 Project Structure

```
CryptoPortfolio/
```

## 🚀 Getting Started

### **Prerequisites:**
- Xcode 15+
- iOS 17+
- macOS Sonoma+

### **Setup:**

1. **Clone repository**
   ```bash
   cd ~/Documents/Personal/CryptoPortfolio
   ```

2. **Open Xcode project**
   ```bash
   open CryptoPortfolio.xcodeproj
   ```

3. **Build & Run**
   - Select simulator
   - Press ⌘ + R
